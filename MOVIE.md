# 🎬 Movie API Documentation (Mongoose + Express)

## 1. Movie Schema (Mongoose)

This schema defines the structure of a **Movie document** stored in MongoDB using **Mongoose**.

```js
import mongoose from "mongoose";

const movieSchema = new mongoose.Schema({
    name: {
        type: String,
        required: true
    },
    description: {
        type: String,
        required: true
    },
    casts: {
        type: [String],
        required: true
    },
    trailerUrl: {
        type: String,
        required: true
    },
    language: {
        type: String,
        required: true
    },
    releaseDate: {
        type: String,
        required: true
    },
    director: {
        type: String,
        required: true
    },
    releaseStatus: {
        type: String,
        default: "RELEASED"
    }
}, { timestamps: true });

const Movie = mongoose.model('Movie', movieSchema);

export default Movie;
```

## 3. 📌 What is `{ timestamps: true }`?

### 👉 Function of `timestamps: true`

When **`timestamps: true`** is enabled, **Mongoose automatically adds two fields** to every document:

```js
createdAt
updatedAt
```

### 🔹 createdAt

* Stores **date & time when the document is created**
* Automatically generated by Mongoose

### 🔹 updatedAt

* Stores **date & time when the document is last updated**
* Automatically updated whenever data is modified

### 📌 Example Document with timestamps

```json
{
  "_id": "65abc123",
  "name": "Inception",
  "description": "Sci-Fi movie",
  "createdAt": "2024-01-10T08:30:15.123Z",
  "updatedAt": "2024-01-12T10:45:20.456Z"
}
```

### ✅ Why timestamps are useful?

* Track record creation time
* Track updates
* Useful for logging, auditing, and sorting data
* No need to manually manage dates

## 5. Movie Routes (Express)

```js
import { createMovie, deleteMovie, getMovie, getMovies, updateMovie } from "../controllers/movie.controller.js";
import MovieMiddlewares from "../middlewares/movie.middlewares.js";

const routes = (app) => {

    app.post('/mba/api/vi/movies', MovieMiddlewares, createMovie);

    app.delete('/mba/api/vi/movies/:Id', deleteMovie);

    app.get('/mba/api/vi/movies/:id', getMovie);

    app.put('/mba/api/vi/movies/:id', updateMovie);

    app.patch('/mba/api/vi/movies/:id', updateMovie);

    app.get('/mba/api/vi/movies', getMovies);
};

export default routes;
```

## 6. API Endpoints Overview

| Method | Endpoint                 | Description          |
| ------ | ------------------------ | -------------------- |
| POST   | `/mba/api/vi/movies`     | Create a new movie   |
| GET    | `/mba/api/vi/movies`     | Get all movies       |
| GET    | `/mba/api/vi/movies/:id` | Get movie by ID      |
| PUT    | `/mba/api/vi/movies/:id` | Update entire movie  |
| PATCH  | `/mba/api/vi/movies/:id` | Update partial movie |
| DELETE | `/mba/api/vi/movies/:Id` | Delete movie         |
